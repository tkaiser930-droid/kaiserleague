2026-11-15 MotoGP classification / Q2 import correction:
- Race and Sprint result rows no longer treat a time-like API `position` value (for example `01:52.123`) as a finishing rank or automatically label it NC. Incomplete ranking data triggers a lookup of the exact selected session's official Stats classification.
- The fallback resolves the Stats classification from the API's `Classification.pdf` / `Fast Lap Rider` session-file links, or from the event's official short code plus `RAC`, `SPR`, or `Q2` session code.
- The Stats table parser reads the numeric `Pos.` and `Rider` columns and retains single-cell section headings, so classified riders and the following NC / DNF groups stay in official order. Unclassified riders receive sequential internal scoring positions after the classified finishers.
- Q2 is fetched as its own event session. If its API result has time values instead of numeric positions, the Q2 Stats classification is parsed and the smallest valid Q2 lap time determines the +3 Fastest Qualifier rider.
- Race `Time/Gap` values are not treated as rider lap times or positions. The separate `Fast Lap Rider` PDF remains the source for the +1 fastest-lap bonus on RAC / SPR.
- Added regression tests reproducing lap-time-in-position API responses, session-metadata URL fallback, Q2 fastest-lap comparison, and grouped NC / first-lap DNF rows. Full `npm run check` passes.

MotoGP HTTP 403 source fix (Nov 2026)
- Use MotoGP's long-standing documented public results API hostname `api.motogp.pulselive.com` first, with `api.pulselive.motogp.com` as an alternate-host fallback. These are two distinct hosts; do not use `api.motogp.com`.
- Use standard browser request headers for the public MotoGP API and include the exact hostname/path in upstream HTTP error messages.
- Do not fetch the Stats Centre HTML fallback: that route can redirect to the MotoGP SSO sign-in and return access errors.
- When the JSON classification does not contain numeric finishing positions, read the selected session's official `Classification.pdf` from the session file link (or the matching event/session path) and parse its Pos/Rider rows plus ordered NC/DNF sections.
- For PDF delivery, try both official MotoGP resources hostnames (`resources.motogp.com` and `resources.motogp.pulselive.com`) if one edge returns an HTTP error.
- Q2's Classification.pdf supplies its actual lap-time column for fastest-qualifier selection. RAC/SPR race-time columns are never treated as fastest laps; their Fast Lap Rider PDFs remain the source for +1 fastest-lap bonuses.

MotoGP 403 diagnostics update:
- The canonical API hostname is now the primary request target, matching the public MotoGP results API documentation and a directly verified seasons endpoint.
- An HTTP 403 from the primary API host triggers a short pause and a retry against the alternate published API hostname.
- HTTP errors include the exact hostname/path, response server/request ID where available, and a short upstream response-body excerpt to distinguish an API-edge 403 from a resource-PDF 403.
- MotoGP PDF fetch errors likewise include the exact resource host and path, so a remaining access block can be isolated without guessing.

HISTORICAL RESULTS AND YEAR WORKSPACES (November 16, 2026)
- Added Commissioner > Historical Results with independent year workspaces from 2010 onward. The season selector switches the Athletes, Scoring, Draft, and Schedule tabs into the selected year's own state.
- Current-season athlete profiles and results remain visible on the public site, including average points per round. Averages are broken down by rider, series, and class; scoring segments at the same scheduled event count as one round.

- Added season unit tests and a server API integration test covering private access, archive atomicity, no point carryover, public API isolation, team identity preservation, and persistence after server restart.
