# Official race-results importer

The Commissioner → Scoring tab includes a preview-first results importer. It accepts:

- Direct HTTPS official results pages when the page exposes an HTML results table.
- Official CSV exports with a Position and Rider (or Driver) column. Optional columns are Number, Team, and Best Lap.

Supported official host groups are restricted server-side by series:

- SMX: supermotocross.com (official results archive and class/session result pages), results.supermotocross.com (legacy archive), supercross.com, results.supercrosslive.com, and results.supercross.com.
- Triple Crown Series: triplecrownseries.ca and its official Trackside / LiveLaps timing hosts. The `https://triplecrownseries.ca/results` archive is resolved to the scheduled year and event. The importer reads the selected CAN 250 or CAN 450 Full Event Results table and uses only the selected Moto 1 / Moto 2 column, not overall-round standings. The active event class tab must be identifiable in the official page markup; ambiguous class pages are rejected rather than mixing 250 and 450 riders.
- MXGP / MXON: mxgp.com, results.mxgp.com, docs.mxgp.com, and fim-moto.com. The official `https://results.mxgp.com/` portal serves classifications at `reslists.aspx`. For MXGP select the Grand Prix, MXGP or MX2 class, and exact Qualifying Race / Race 1 / Race 2 classification, then paste the filtered `reslists.aspx` URL including its query string. For MXON select the Motocross of Nations event and MX2 / MXGP / Open qualifying or Moto 1 / 2 / 3 classification. The importer validates the classification heading against the selected class/session where the source exposes it. Rider numbers and best-lap times are imported when present.
- F1: formula1.com. The season `/en/results` archive is resolved to the event matching the selected schedule name/date, then the selected Race Result or Sprint Result page. The importer also reads `/qualifying` for Grand Prix sessions or `/sprint-qualifying` for Sprint sessions and preselects the fastest-qualifier bonus for the driver in P1. For Grand Prix sessions, the official Fastest Laps page is also read when available so the fastest-lap bonus can be preselected; the event-wide fastest-laps page is not applied to Sprint sessions. Rows marked `NC` are retained, displayed as `NC`, and assigned consecutive internal scoring slots after classified finishers in the exact order shown by the official classification.
- MotoGP: motogp.com and its official PulseLive results API. The importer selects the official `RAC` Race or `SPR` Sprint classification based on the scoring tab, and separately reads `Q2` for the fastest-qualifier bonus. It then follows the `Fast Lap Rider` file link exposed by that exact session (or its paired `Classification.pdf` resource URL) to the session-specific `FastLapRider.pdf`. The PDF lists each rider in fastest-lap order; the first ranked rider is used for the +1 Fastest Lap bonus. The PDF parser is installed through the `pdfjs-dist` dependency during `npm install` / Render build. This dedicated MotoGP PDF is supported; arbitrary PDF or Excel uploads are still not supported.

The server rejects non-HTTPS URLs, unknown hosts, non-standard ports, and redirects outside the approved domain list. Source pages are limited to 5 MB and requests time out after 15 seconds. For SMX, the importer follows the selected event on the official SuperMotocross archive to its class-specific result link (for example, `/250-moto-1/`, `/450-moto-1/`, `/250-main-event/`, `/450-main-event/`, or `/overall/250/`). It then verifies that the fetched page matches the selected 250 or 450 class before parsing. Official rider image alt text is used to avoid mixing hometown text into rider names; official number suffixes such as `1W` are preserved. For F1, the archive is matched by scheduled event date and name; a Sprint selection follows the event's official Sprint result link and Sprint Qualifying page, while Grand Prix selects Race Result and the Qualifying page. The importer does not write league scores automatically. It previews rows, matches riders to the selected fantasy division by name and number, and then loads matched positions into the existing scoring table for commissioner review. When Best Lap values are included and the selected scoring mode has a generic Fastest Lap bonus, the quickest classified rider's Fastest Lap checkbox is preselected. Other bonuses must be checked by the commissioner.

Official pages that require sign-in, render results only after client-side scripts, or provide only PDF / Excel files may not be parsed directly. In those cases, use the official CSV export if available. The MotoGP Fast Lap Rider PDF is a specific supported exception: it is fetched from the selected official session link and parsed server-side with `pdfjs-dist`. General PDF and Excel imports are not supported.

Run the site with `npm start` (not VS Code Live Server) because URL fetching is performed by the Node server at `/api/results/preview`.
