KAISER FAMILY FANTASY SMX — RENDER + GITHUB SAVING

SHARED LIVE LEAGUE (RECOMMENDED)
1. Deploy this project to the existing Render web service using the included render.yaml.
2. Confirm the service has its persistent disk mounted at /var/data and DATA_DIR=/var/data.
3. In Render > Service > Environment, confirm:
   GITHUB_TOKEN = your fine-grained token (secret; do not put it in website files)
   GITHUB_REPOSITORY = tkaiser930-droid/LeagueSave
   GITHUB_DATA_PATH = league-data/league-data.json
   GITHUB_AUTO_BACKUP = true
   GITHUB_BACKUP_PASSWORD = your private manual-backup password
4. The token must have Contents: Read and write and Metadata: Read access to tkaiser930-droid/LeagueSave.
5. Open the Render-hosted website URL (not VS Code Live Server).

WHAT HAPPENS
- Every normal league update is written to Render's persistent disk first.
- The server then automatically queues a GitHub commit of the same league-data.json to tkaiser930-droid/LeagueSave.
- On server startup, Render and GitHub saves are compared by savedAt timestamp; the newer save is loaded.
- Commissioner > Data & Backup > Save to Primary Storage + GitHub forces an immediate save and waits for GitHub to confirm it. The page reports partial failure honestly if Render saved but GitHub did not.
- Data & Backup displays the Render and GitHub save timestamps and any backup error.

LOCAL DEVELOPMENT
1. Stop VS Code Live Server.
2. Copy .env.example to .env and enter the GitHub token and backup password.
3. Run npm start from the project folder.
4. Open http://localhost:10000.
5. Local mode saves to data/league-data.json and mirrors to GitHub. It does not write to the Render persistent disk.

IMPORTANT
- VS Code Live Server is static-only. Its Browser-only mode saves only in that browser and does not send changes to Render or GitHub.
- Use the Render-hosted website for shared Render + GitHub storage.
- The GitHub repository is a backup of league data JSON, not a mirror of the website source code.
- Never commit .env or expose GITHUB_TOKEN in browser code. The project .gitignore excludes .env and data/league-data.json.
